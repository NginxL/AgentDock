## 可重复测量

`python3 scripts/benchmarks/cancellation.py --runs 8000` 在临时数据库里生成已完成的运行记录，分别删除和恢复索引，对同一查询各测三次、取中位数。不会打开用户数据库。

2026-10-08，本机 Python 3.9.6、8,000 条记录：修复前 **2,235.211 ms**，修复后 **6.867 ms**（约 **325 倍**）。绝对时间随设备变化，不作为脆弱的单元测试门槛。

相关回归：`python3 -m unittest tests.test_store tests.test_account_runtime -q`，44 项通过。
