# 验证与兼容性

[English](REVIEW.md) · **简体中文** · [返回说明文档](../README.zh-CN.md)

## 实现状态

AgentDock 由本地 React 界面、Python 标准库服务和 SQLite 存储组成。ACP 管理 Codex 和 Claude 适配器会话；MCP 提供项目邮箱与记忆工具。AgentMeter 保持独立，通过 `--probe` 提供只读额度数据。

| 领域 | 已实现 | 实机验收项或能力边界 |
| --- | --- | --- |
| 界面 | 中英文切换、项目、角色、会话、任务事件、运行与取消入口、权限审批。 | 尚未启动应用进行浏览器验收；当前图片已明确标记为设计示意图。 |
| Agent 接入 | 通过标准输入与标准输出使用 ACP v1，支持初始化、会话、任务提示、更新、权限与取消；命令由服务端配置。 | 真实 `codex-acp`、`claude-agent-acp` 版本与账号兼容性待验证。 |
| 通信 | 绑定发送者身份的同项目邮箱、消息去重与确认；六个 MCP 工具。 | 真实模型的工具调用行为待验证；未实现自动唤醒与自主团队循环。 |
| 记忆 | 项目隔离、关键词检索、版本冲突检测、Agent 提议、人工批准、软归档与数据库历史记录。 | 未实现向量检索、自动提取、完整版本历史界面与跨项目共享。 |
| 额度 | 对固定提供商执行 AgentMeter 探测，支持超时、限流、未知、过期与错误状态，以及手动账期记录。 | 真实登录、钥匙串提示与额度刷新待验证；不保证所有账号或提供商接口长期可用。 |
| 生命周期 | 进程组取消、审批过期、重叠工作目录互斥、数据库单实例锁，以及重启后不重放任务。 | 未实现操作系统级沙箱、自动创建 Git 工作树与远程多用户访问。 |

Claude ACP 适配器使用 Agent SDK，执行时要求 API 密钥。展示现有 Pro/Max 订阅额度不代表获得 SDK 推理授权。在选择 ACP、未修改的命令行客户端或其他官方支持的执行方式时，必须在启动前审查认证兼容性。

## 隔离验证

后端测试使用临时 SQLite 数据库、直接调用 HTTP 请求分发器，以及模拟 ACP/AgentMeter 的 Python 子进程。前端测试使用模拟 DOM 与 HTTP 响应。构建生成静态资源。这些检查均不会启动 AgentDock HTTP 服务、真实编程 Agent，也不会向提供商发起额度请求。

已在 macOS、Python 3.9.6、Node.js 20.20.2 环境下通过 **45 项后端测试与 16 项界面测试**，以及 Python 字节码编译、TypeScript 检查和 Vite 生产构建。界面回归测试覆盖延迟状态刷新和乱序轮询，验证新建会话后提交的任务会发往新会话。

验证范围包括：拒绝跨项目与跨身份访问、取消后工具权限失效、比较并交换的并发写入冲突、记忆审批来源追踪、拒绝过期审批、异常协议消息、输出大小限制、子进程组清理、拒绝多个实例同时使用同一数据库、父子目录冲突、额度缓存过期或未知，以及界面请求与语言切换。

无需启动应用，可执行以下命令复现检查：

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q agentdock tests
cd web
npm ci --ignore-scripts
npm test
npm run build
```

持续集成在 Python 3.9/3.12 和 Node 20 环境下执行这些隔离检查。检查通过不代表已确认真实提供商的兼容性。真实 Agent 执行与真实额度刷新尚未通过验收测试。

## 代码审查清单

1. [架构设计](ARCHITECTURE.zh-CN.md)：ACP、MCP、额度和共享记忆的边界，以及显式执行与人工审核要求。
2. [存储模块](../agentdock/store.py)：项目隔离、消息语义、记忆版本与来源、运行权限和锁。
3. [运行模块](../agentdock/runtime.py)与 [MCP 桥接模块](../agentdock/mcp.py)：ACP 字段、审批有效期、工具权限与取消流程。
4. [额度桥接模块](../agentdock/quota.py)与[本地服务](../agentdock/server.py)：额度准确性、本地认证、关闭顺序与默认禁用执行。
5. [界面](../web/src/)与[测试](../tests/)：可见状态与 API 的一致性、错误处理和边界覆盖。

## 实机验收要求

仅在明确决定运行预览版后，开展以下验收：

- 固定适配器版本，在可丢弃且可信的 Git 工作树中验证官方认证方式。
- 分别运行一个 Codex 任务与一个 Claude 任务，确认流式结果、权限请求、完整取消与重启恢复均正常。
- 双向验证 Codex 与 Claude 的邮箱通信，确认不会产生失控的自动调用；记忆提议须经审核，版本冲突须在界面可见。
- 刷新真实 AgentMeter 额度，与官方用量页面核对剩余额度和重置时间，并覆盖认证失败与缓存过期场景。
- 检查中文与英文界面，截取不含私人信息的演示图片。

预览版不会安装系统服务、设置开机启动、注册全局 MCP 配置、修改 AgentMeter 或更改已有提供商登录状态。
