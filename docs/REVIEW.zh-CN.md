## 实现状态

AgentDock 0.2 由 React 界面、Python 标准库服务和 SQLite 存储组成。任务由原生 Codex 与 Claude Code 进程执行；调度器保留原生会话标识，负责派发工作和回传结果。五个受限 MCP 工具提供协作和已审核的项目记忆。macOS 安装版内置独立额度程序，通过 `--probe` 提供去敏快照。

| 领域 | 已实现 | 验收边界 |
| --- | --- | --- |
| 界面 | 默认中文、英语切换、项目导航、原生会话状态、对话事件、任务派发、审批、共享记忆和额度摘要。 | 离线预览通过真实界面渲染虚构测试数据，不代表真实模型执行、订阅或额度已经可用。 |
| 原生接入 | Codex 应用服务的 JSON-RPC、Claude Code 流式 JSON 控制消息；原生标识续接、文本与工具事件、权限决策、超时和进程组清理。 | 已核对官方资料及本机命令行客户端元信息中的协议契约；真实登录和模型执行仍待验证。 |
| 协作 | 自动派发、按工作目录排队、原生会话续接、结果回传、重试去重、深度与运行次数上限、后代任务取消。 | 真实模型的委派行为和长时间协作需要实机验收。 |
| 共享记忆 | 项目隔离、字面关键词检索、版本冲突、Agent 提议、人工批准、软归档和数据库历史记录。 | 尚未实现向量检索、自动提取、完整版本历史界面和跨项目共享。 |
| 额度 | Codex 与 Claude 的内置额度探测，超时与限流处理，未知、过期和错误状态，以及独立的手动订阅记录。 | 本机 Codex／Claude 读取已通过；钥匙串交互提示、更多账号配置与官方用量页核对仍待验证。 |
| 恢复 | 数据库增量迁移、旧邮箱历史保留、原生会话唯一归属、重叠工作目录互斥、数据库实例锁，以及重启后不自动重放任务。 | 不支持导入 Codex App 或其他终端的既有会话；尚未实现远程设备、自动创建 Git 工作树或远程多用户访问。 |

## 提供商兼容性

| 提供商 | 本地核对版本 | 使用的协议契约 |
| --- | --- | --- |
| Codex | `codex-cli 0.154.0` | 导出的应用服务 JSON 模式及官方文档：`initialize`、`thread/start`、`thread/resume`、`turn/start`、审批请求、事件通知和 `turn/interrupt`。 |
| Claude Code | `2.1.268` | 原生命令行帮助与 Anthropic 公开的控制协议定义：`--print`、`--input-format stream-json`、`--output-format stream-json`、`--resume`、`--session-id`，以及标准输入输出上的权限请求。 |

以上是**协议契约核对版本**，不代表已完成端到端兼容性验收，也不代表所有版本通用的最低版本要求。Claude 适配器使用 `--permission-mode manual` 和 `--permission-prompt-tool stdio`；如果客户端不接受这些参数，将报错，不会降级为绕过权限检查。认证由原生命令行客户端按其支持的本地配置处理。AgentDock 不强制要求 API 密钥，不导出提供商凭据，不修改登录状态，也不安装 Agent SDK。

Codex 使用本次运行拥有的应用服务进程，配置为 `workspace-write`、`untrusted` 命令审批和用户审核；仅新建或恢复 AgentDock 拥有的会话。Claude 使用人工审批权限模式，将权限提示发送给工作台；批准后只返回该次工具调用的原始输入，拒绝时不授予权限。原生客户端已有的策略和受管限制仍然生效。AgentDock 自身不提供独立的操作系统沙箱。

每轮前台任务结束后原生进程退出，原生对话保留供下次恢复。Claude 子进程环境设置 `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`，按[官方环境变量说明](https://code.claude.com/docs/en/env-vars)禁用原生后台任务；此设置不修改用户全局环境，也不影响其他 Claude 进程。已登记 Agent 通过 AgentDock 调度器协作。这是会话续接，不是附加到已经运行的桌面或终端进程。额度展示与执行认证彼此独立：能读取额度快照，不代表已经确认该提供商可以执行任务。

官方协议资料：[Codex 应用服务](https://learn.chatgpt.com/docs/app-server)、[Claude Code 命令行](https://code.claude.com/docs/en/cli-reference)、[Anthropic 控制协议实现](https://github.com/anthropics/claude-agent-sdk-python/blob/main/src/claude_agent_sdk/_internal/query.py)。

## 隔离验证

后端检查使用临时 SQLite 数据库、模拟原生命令行的进程和模拟额度探测。调度集成测试使用临时回环 HTTP 接口及真实 MCP 桥接程序，但编程 Agent 均为确定性的本地测试程序，不涉及真实模型、提供商登录或在线额度接口。

前端检查使用模拟 DOM 与 HTTP 响应。生产构建校验 TypeScript 并生成静态资源。离线演示渲染虚构的项目、对话和额度数据，禁用执行、修改和提供商请求；该模式的截图仅展示界面。

| 测试领域 | 覆盖范围 |
| --- | --- |
| 原生协议 | 新建与恢复会话、Codex 恢复时不返回历史轮次、原生身份一致性、流式输出与最终文本去重、批准与拒绝的完整链路、仅作用于 Claude 子进程的前台执行设置、会话或轮次错配、无效 JSON、提前退出和错误去敏。 |
| 资源边界 | 输出限制、审批过期、审批阻塞期间的运行超时、取消、后代进程清理，以及 MCP 权限撤销。 |
| 调度与 MCP | 自动派发并返回确切的原发送会话、嵌套或多个子任务完成后的最终结果结算、排队任务调度、工作目录互斥、幂等性、失败传播、取消，以及回传容量预留。 |
| 存储与授权 | 项目和发送者隔离、自定义角色持久化及管理员编辑权限、原生会话归属、数据库迁移、重启行为、单实例锁、记忆版本冲突和审核来源。 |
| 额度与界面 | 创建、编辑和清空角色且不按服务预设职责，角色更新用于后续轮次，保留失败编辑草稿及原生历史；区分过期、未知和真实零额度，进入额度页自动刷新、重复点击合并、延迟状态更新、安全渲染、语言切换，以及可见状态与 API 记录的一致性。 |

无需启动真实 Agent，即可复现自动化检查：

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q agentdock tests
cd web
npm ci --ignore-scripts
npm test
npm run build
cd ..
swift run --package-path native MeterChecks
swift run --package-path native MeterProviderChecks
swift run --package-path native DesktopChecks
```

[持续集成](../.github/workflows/check.yml)在 Python 3.9、3.12 环境下执行后端检查，在 Node 20 环境下执行前端检查，并在 macOS 构建桌面程序、执行离线额度解析和提供商回归检查。桌面检查覆盖菜单额度格式、缓存过期、未知数值、摘要长度和中英文显示；接口及界面检查覆盖只读缓存、进入额度页自动刷新、按需显示授权入口和语言同步。定时器检查通过模拟时间验证 600 秒间隔、提供商失败隔离、非交互读取、错过周期处理及退出清理。通过这些检查表示本地协议契约及测试覆盖的生命周期行为符合预期，不代表实际提供商账号、模型决策、其他客户端版本或在线额度准确性已经通过验证。

## 实机验收要求

真实执行需要作为独立步骤显式启用。在可信、可丢弃的工作目录中完成以下检查后，再将预览版用于日常工作：

1. 验证原生命令行客户端的认证和配置版本；每个提供商连续执行两轮任务，确认第二轮恢复同一原生对话。
2. 验证权限批准、拒绝、过期、取消与重启行为；确认排队任务取消后不会启动，未完成任务重启后不会重放。
3. 运行 Codex → Claude → Codex 协作和嵌套委派，确认原发送方在原会话中收到最终结果，重复委派受到上限约束。
4. 验证共享记忆提议审核、版本冲突和项目隔离；将真实剩余额度与重置时间同官方用量页面核对，覆盖失败和缓存过期状态。
5. 使用真实会话检查两种界面语言，确认错误、排队、审批、结果和未知额度状态清楚易懂，且不暴露凭据。

桌面启动、自动连接、退出清理及 Codex／Claude 真实额度读取已通过本机 macOS 验证。交互式钥匙串提示、更多账号配置及与官方用量页的一致性仍待核对。真实 Agent 执行与协作仍需实机验收；既有会话导入尚未实现。安装器不注册后台服务、开机启动项或全局 MCP 配置，也不更改提供方登录状态。
